# Web2Video

把科普等口播做成网页场景，配 TTS 与时间轴动画，再按语言导出视频。

建议 **Chrome 或 Edge**。

```bash
npm install
npm run dev
```

## 功能

- 多种版面：封面、图文左右、要点、金句、步骤、全幅图
- 入场动画与底部时间轴（相对配音时长的比例，换语言自动对齐）
- Edge TTS 配音（免费）；也可在配音面板填写 Azure / OpenAI Key
- 配音角色可增删，按语言指定
- 预设版面 + 自定义版面（公共元件：标题、正文、图片、列表、色块等）
- 时间轴每元件一行，可拖入场/退场
- 一键机翻：中、英、日、法、德、俄、西班牙、葡萄牙、意大利
- 按语言导出 WebM（画面 + 语音）
- 工程保存在文件夹的 `project.json` 与 `media/`

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| Ctrl+S | 保存 |
| Ctrl+E | 导出 |
| Ctrl+Z / Y | 撤销 / 重做 |
| ? | 帮助 |
